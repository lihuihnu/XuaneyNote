# B5.3 密码保护完整备份：手机/平板 SAF 真机验收清单

**阶段**：PR-B Draft，B5.2 源码已由官方 Run 39093609921 验证。B5.3 是新 Compose/SAF 功能，只有新 CI 通过并实际真机执行以下操作后，才能考虑正式合并/交付；不修改历史 Room Schema。

## 测试准备

在独立的可清空测试安装环境中使用合成笔记（两篇中文和 Emoji 正文、一篇在回收站、一张 JPEG/PNG/WebP 附件），设置深色主题。正式与临时 Debug 签名可能不同，不要卸载唯一保存私人笔记的旧安装。若已有 B3.4 图片测试 APK，安装新 APK 前核对应用包名、证书指纹及重组后的 SHA-256。

## 加密导出

- [ ] 设置页原 JSON v1、明文 ZIP v2 四个按钮仍在；另有“导出密码保护备份”和“导入密码保护备份”。
- [ ] 密码为空、过短、两次输入不一致时“选择保存位置”不可点击；弹窗可取消，**不会弹出 SAF 创建文件**。
- [ ] 输入两次一致、长度不少于 12 的高强度合成密码，SAF CreateDocument 创建本地 \`.xuaney.aes.zip\`；输出必须关闭、通过同一 URI 读回完整认证后才报告成功。
- [ ] SAF 用户取消不生成文件；旋转/后台恢复密码不能从 SavedState 恢复，也不应造成明文回退。需记录该环境的表现。
- [ ] 使用系统文件管理器确认已生成文件；文件内不能直接看到用户笔记标题、图片 SHA 或 \`notes.json\` 外部条目名，外层固定单条目 \`payload.xuaney.zip\`。**文件大小等元数据仍可见**。

## 加密导入、失败与确认

- [ ] 选择已导出的文件，输入正确密码后显示经认证的笔记、回收站、图片数量和主题的**恢复预览**，原笔记尚未改变。
- [ ] 点击取消，原有笔记和图片不变；重新导入并点击确认恢复，缺失数据得到恢复，已存在相同数据跳过，冲突生成稳定副本；重复导入不无限复制。
- [ ] 输入错误密码、不支持格式、截断/修改后的 ZIP：必须报错，**不得写入或覆盖任何既有笔记、回收站、附件**；允许重新打开导入入口再输入密码。
- [ ] 尝试导入明文 ZIP 到加密入口应被拒绝，不能误当加密成功；明文专用入口应照常恢复真正明文文件。
- [ ] 文件提供者不支持重新打开、无空间、读回数据被修改时必须显示失败，不得输出“备份完成”；本机数据不受影响。

## 加密、隐私与环境记录

- [ ] 明确显示 AES-256 ZIP 密码保护但 WinZip AES 使用弱 KDF（PBKDF2 1000 次），**建议使用高熵长口令**。密码无法找回；文件大小、ZIP 外层元数据可能暴露。
- [ ] 说明中文/Emoji 密码在部分第三方 ZIP 解压软件上可能不兼容。不要把 CI 上 Zip4j/pyzipper 成功表述为通用 ZIP 工具保证。
- [ ] 无互联网权限、云同步、用户账户、埋点和第三方密码提交；密码不作为应用日志、Crash、SavedState、数据库内容存储。
- [ ] 记录手机型号、Android 版本、测试 APK 的 source/tested SHA、签名、所选 SAF provider、执行结果；单独注明是否完成**同一签名**跨版本覆盖升级。
